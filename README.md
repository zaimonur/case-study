# EatBetter Case Study

Bu repository, EatBetter Full Stack Developer Case Study çalışmasının backend ve mobile projelerini tek bir monorepo altında barındırır.

## Projeler

- [`case-study-eatbetter-backend/`](./case-study-eatbetter-backend/): Go, PostgreSQL ve Docker tabanlı backend uygulaması.
- [`case-study-eatbetter-mobile/`](./case-study-eatbetter-mobile/): React Native ve Expo tabanlı mobile uygulama.

Her projenin kurulum ve çalıştırma ayrıntıları kendi klasöründeki README dosyasında yer alacaktır.
